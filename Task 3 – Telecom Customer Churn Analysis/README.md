# Task 3 – Telecom Customer Churn Analysis

## Project Overview
Analyzed telecom customer data to understand churn behavior, identify high-risk customers, and evaluate customer retention patterns.

## Objectives
- Analyze customer churn rates.
- Identify high-risk customer segments.
- Study contract types and payment methods.
- Understand factors influencing customer retention.

## Tools & Technologies
- Python
- Pandas
- Matplotlib

## Key Results
- Total Customers: 7,043
- Churned Customers: 1,869
- Churn Rate: 26.54%
- High-Risk Customers: 49.37%

## Key Insights
- Evaluated customer churn patterns.
- Identified customer segments with higher churn risk.
- Analyzed retention-related factors.
