# Datheon Data Analytics & Power BI Internship

## About This Repository
This repository contains four data analytics and Power BI projects completed as part of the Datheon Data Analytics & Power BI Internship.

## Projects

### Task 1 – Superstore Sales Analysis
- Performed data cleaning and exploratory data analysis using Python.
- Analyzed sales, profit, orders, and customer performance.
- Created visualizations to identify business insights.

### Task 2 – Power BI Superstore Dashboard
- Designed a Star Schema data model.
- Created Fact Orders, Dim Customer, Dim Product, and Dim Date tables.
- Developed interactive dashboards with KPI cards, slicers, and profitability analysis.

### Task 3 – Telecom Customer Churn Analysis
- Analyzed customer churn patterns using the IBM Telco Churn dataset.
- Identified high-risk customer segments.
- Evaluated churn rate and customer retention metrics.

### Task 4 – Financial Statement Variance Analysis
- Analyzed financial performance using Power BI.
- Created KPI cards for Profit, Gross Sales, Discounts, and COGS.
- Developed an interactive financial dashboard.
